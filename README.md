# 第三章电脑实验：同一个二极管电路里的 HB、变换矩阵和混频

## 推荐路线

先用 MATLAB 把计算过程看清楚，再考虑移植到 ADS。这里已经提供可运行的第一版，不需要额外工具箱。

学习目标是亲眼看到：本振使二极管周期导通；谐波平衡算出这个工作状态；在该状态附近求导得到时变电导、电容；变换矩阵预测弱射频信号转换出的中频；原始电路的时域积分检查这些预测是否可信。

主实验采用牛顿法求 HB。优化法、分裂法和反射法是同一 HB 方程的其他求解路线，留到理解主实验后再替换求解器。本版本没有实现后三种算法。这样第一次阅读时，注意力可以放在电路和频率转换上。

## 运行

下载或克隆本仓库后，在 MATLAB 中将当前文件夹切换到包含 `run_hb_mixer_lab.m` 的目录，然后在命令窗口运行：

```matlab
results = run_hb_mixer_lab;
```

会计算并打开四个图窗，同时把 PNG、可重新打开的 FIG、MAT 数据和 CSV 表写入本文件旁边的 `results` 文件夹。运行中包含多次独立时域积分，请等命令窗口出现 `All checks passed`。

只想查看上次已经算好的图，不必重新计算：

```matlab
openfig('results/01_harmonic_balance.fig')
openfig('results/02_conversion_matrix.fig')
openfig('results/03_time_domain_check.fig')
openfig('results/04_convergence_and_limits.fig')
```

无图窗批处理：`results = run_hb_mixer_lab(false);`。默认会覆盖本实验自己的上一次计算结果。

## 电路和参数

```text
                         Rs = 50 ohm
    vs(t)  o-------------/\/\/\---------o v(t)
           |                           |
           |                  +--------+--------+
           |                  |        |        |
       理想电压源             二极管D   Cpar    RL=1k
           |                (含结电荷) |        |
           |                  |        |        |
    GND    o------------------+--------+--------+
```

二极管正向电流从节点流向地，正向导通时限制正半周期电压。

源电压为 `Vdc + Vlo*cos(2*pi*flo*t) + Vrf*cos(2*pi*frf*t)`。

| 参数 | 默认值 | 含义 |
|---|---|---|
| Rs | 50 Ω | 源串联电阻 |
| RL | 1 kΩ | 节点到地的宽带负载 |
| Vdc | 0.05 V | 电源直流分量，不是实际二极管直流电压 |
| Vlo | 0.50 V 峰值 | 本振源电压 |
| flo | 1 GHz | 本振频率 |
| Vrf | 1 mV 峰值 | 射频源电压 |
| frf | 1.1 GHz | 射频频率 |
| fif | 100 MHz | 要观察的差频 |
| Is | 1 μA | 二极管饱和电流参数 |
| nVT | 26 mV | 指数电流电压尺度 |
| Cj0 | 0.25 pF | 零偏结电容参数 |
| Vj | 0.7 V | 结势垒模型参数 |
| Cpar | 0.15 pF | 线性并联寄生电容 |
| K | 47 | HB 保留直流和前 K 阶谐波 |
| N | 17 | 变换矩阵保留频率编号 -N 到 N |
| M | 2048 | 一个本振周期计算非线性波形的采样数 |

这是有物理电路方程的教学模型，不是某款商用二极管的参数拟合，也不是完整三端口射频产品设计。本振与射频由理想源直接相加，真实硬件通常还需合路、偏置和匹配网络。本版本未增加物理中频滤波器，图中的中频波形是从节点电压提取的 100 MHz 分量。负载上还存在 LO、RF 等其他频率。

## 电路方程

节点 KCL：

\[
\frac{v_s-v}{R_s}=\frac{v}{R_L}+i_D(v)+\frac{dq(v)}{dt}.
\]

\[
i_D(v)=I_s[\exp(v/(nV_T))-1].
\]

总电荷 q 包括非线性结电荷和 Cpar*v。默认工作区域内，结电荷采用：

\[
q_j(v)=2C_{j0}V_j(1-\sqrt{1-v/V_j}),\qquad
c_j(v)=\frac{C_{j0}}{\sqrt{1-v/V_j}}.
\]

超过 Fc*Vj（Fc=0.5）时，用保持电荷、电容及电容一阶导数连续的延拓，避免结模型在 v=Vj 处的奇点。程序没有把指数电流人为截平。

## 建议分六次做，每次只回答一个问题

### 实验一：没有 RF，本振怎样改变二极管？

看图窗 1 的源电压、节点电压和二极管电流。解释为什么源电压是正弦，器件端口电压却失真；为什么电流集中在周期的一部分；为什么出现直流和高次谐波。

对应课件 3.1.1。检查：`results.hb.v` 是节点电压，不是源电压；`results.hb.id` 是器件电流。

### 实验二：谐波平衡到底在求什么？

看图窗 1 的残差曲线和 `solve_hb`、`hb_residual`。

电压系数采用实数排列：`[Vdc; a1; ...; aK; b1; ...; bK]`，对应 `Vdc + sum(ak*cos(k*theta)+bk*sin(k*theta))`。

程序将系数变成波形，计算器件电流和电荷，再投影回频域，形成 KCL 残差。雅可比同时包含微分电导和微分电容，牛顿法计算修正量，并用阻尼和本振幅度渐增改善收敛。

对应课件 3.1.2。验证：牛顿残差小于给定电流容差；另外与原始微分方程独立积分的 LO 波形对照。

### 实验三：非线性器件怎样变成线性时变元件？

看图窗 2 的 `g(t)` 和 `c(t)`。

\[
g(t)=\left.di_D/dv\right|_{v=v_P(t)},\qquad
c(t)=\left.dq/dv\right|_{v=v_P(t)}.
\]

说明它们为何是随时间变化的曲线，而不是一个恒定电阻、电容。前一步的同一个本振工作波形，是这一步求导的依据。

对应课件 3.2 第24—28页。

### 实验四：从矩阵看到 RF 变成 IF

本例严格采用 `f_n=f_IF+n*f_LO`。Vn 是一个频率族的峰值相量，实际增量波形为 `real(sum(Vn*exp(j*2*pi*fn*t)))`。

| n | 有符号频率 | 解释 |
|---|---|---|
| -1 | -0.9 GHz | 代表实际 0.9 GHz 分量的共轭相量 |
| 0 | 0.1 GHz | 中频 IF，编号0不是直流 |
| 1 | 1.1 GHz | 射频 RF，只有该行有外加小信号源 |
| 2 | 2.1 GHz | 上变频分量 |

\[
G_{nm}=G_{n-m},\quad C_{nm}=C_{n-m},\quad
[ (1/R_s+1/R_L)I+G+j\Omega C ]V=I_s.
\]

其中 Ω 对角线是带符号的实际角频率；频率矩阵必须左乘 C。原有线性外部网络在频率上不耦合，G、C 的非对角项负责频率间转换。G 和 C 里的 n、m 是频率编号，不能混为物理端口编号。

在 MATLAB 中查看：

```matlab
results.cm.G
results.cm.C
results.cm.Y
results.cm.V
results.cm.n
```

看图窗 2、3：实际混频谱线不等高。关掉 LO 的内部验证还会确认一阶转换模型没有 IF 输出。

对应课件 3.2 第29—36页。

### 实验五：谐波和边带到底保留多少？

看图窗 4 前两幅图以及 `harmonics.csv`、`sidebands.csv`。

K 从3增加到47，所有对应方程都能迭代收敛，但 IF 结果会变化。另一个实验固定已求好的大信号状态，增加 N；这是不同的截断。

同一个 [-N,N] 矩阵需要 g、c 的傅里叶系数到 ±2N。默认 K=47、N=17；N 扫描最大23。不能把“电压波形截到某阶”理解成器件导数波形也严格止于该阶。

M 翻倍的检查针对非线性波形的采样误差。它不替代 K 或 N 的收敛检查。

### 实验六：RF 多大时，小信号近似失效？

看图窗 4 后两幅图和 `rf_amplitude.csv`。程序把射频源峰值从0.1 mV增加到300 mV。

变换矩阵以固定 LO 工作状态为基础，所以总是预测 IF 与 RF 成正比。原始非线性 ODE 不作小信号展开，在强 RF 时会逐渐偏离这条预测。

误差使用复数相量之差，同时检查幅度和相位，不能只看两条幅度曲线是否重合。

## 验证方法和结果文件

原始 ODE 与 HB 独立：它直接对节点电压积分，不使用 HB 的傅里叶系数或变换矩阵。时间变量 u=fLO*t 仅作单位缩放。先积分40个LO周期以消除暂态，再观察40个周期；使用跨一个10周期公共周期的波形差检查稳态。均匀采样不重复末端点，观察窗口包含整数个 IF 周期，避免谱泄漏。

程序检查：

- HB 残差与独立 ODE 的 LO 波形。
- 弱 RF 下完整增量波形与 IF 复相量。
- K、N、M 的增加是否使目标结果稳定。
- ODE 容差收紧后，IF 结果是否稳定。
- 去掉 LO 后，一阶 IF 输出是否消失。
- HB 雅可比与中心差分方向导数是否一致。
- 强 RF 扫描是否确实显示小信号近似的偏差。

具体数值见 `results/verification.txt`。这些验证针对这个教学电路和默认参数，不等价于商业器件模型校准或真实硬件验证。

在本机 MATLAB R2025a 的默认参数验证中：

| 项目 | 结果 |
|---|---:|
| RF源峰值1mV时，变换矩阵预测的IF峰值 | 255.218 μV |
| IF复相量与完整非线性ODE的相对误差 | 0.00480% |
| LO波形相对RMS误差 | 0.0000724% |
| 小信号完整增量波形相对RMS误差 | 0.643% |
| RF源峰值300mV时，固定LO变换矩阵的IF复相量误差 | 6.20% |

IF误差小不表示整个波形的每个分量都具有相同精度。上表刻意同时报告目标IF和完整增量波形，两者对应不同的验证范围。

负载 IF 功率采用 `abs(Vif)^2/(2*RL)`。射频源可用功率采用开路峰值源电压对应的 `Vrf^2/(8*Rs)`。程序的 conversion_gain_dB 是两者之比，不是把电压比冒充功率转换增益。

## 阅读代码的顺序

1. 主函数最前面的参数和电路说明。
2. `diode`：器件电流、电荷、导数。
3. `hb_residual`，再读 `solve_hb`：方程如何建立和求解。
4. `conversion`：导数傅里叶系数、频率索引和矩阵。
5. `ode_rhs`、`transient`：原始电路的独立求解。
6. 最后读绘图与精度扫描，不要第一次就逐行阅读整个文件。

## 本版参数修改的边界

这是一份围绕默认电路讲课的脚本，图中文字、频率编号和验证扫描按1GHz/1.1GHz设计。不要只改频率数字而保留原观察窗口；改频率时还要重新安排公共周期、激励所在行和取谱频率。改 K、N 或M时应同时调整相应收敛比较与说明。本版不是任意电路的通用仿真器。

后续可以分别做：保持电路不变替换 HB 求解算法；添加实际中频滤波支路；建立采用相同模型和终端的 ADS 工程作对照。这些是后续实验，不属于已经实现的功能。
